PRIMARY RUN / SOLID HANDOFFS

Luồng canonical đang được code hóa

Các stage 01–10 nằm trên một trục duy nhất. RAG và fine-tune chỉ mở rộng candidate/navigation hoặc tạo proposal; không được đưa số vào planner. E2E không tìm câu trả lời mới và không có quyền tự promote.

SAME-RUN AUTHORITY

E2E đứng trước Submission Compiler

Compiler nhận resolved prediction và E2E receipt. Nếu receipt là `ABSTAIN`, package best-effort vẫn có thể giữ coverage, nhưng ledger ghi rõ trạng thái và strict release bị block.

PROMPT CONTRACT

English instruction, Vietnamese context

  • Giữ nguyên: question_raw_vi, ticker, period, source labels, coordinates, hashes.
  • Canonical: dùng JSON keys/enums English ổn định để parser và evaluator không phụ thuộc ngôn ngữ.
  • Top-k: chỉ là navigation metadata; model không được copy numeric value từ candidate.
  • Thiếu context: model trả ABSTAIN, không đoán period/scope/unit/operand.
  • Model thật: worker Kaggle dùng Qwen checkpoint/revision cố định; lỗi output trở thành record invalid/ABSTAIN.
Điểm cần nhớ: `ResolvedPrediction` là kết quả resolver, chưa đồng nghĩa `VERIFIED`. `E2EReceipt` là proof/blocked receipt. `SubmissionLedger` là delivery accounting. `ImprovementRecord` là tín hiệu cho version kế tiếp. Bốn artifact này không được gộp thành một nhãn “model đúng”.
